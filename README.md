# Cookie Clicker Web Application

A simple, interactive web page featuring a centered cookie with a click counter, floating "+1" animations, and persistence.

## Features

- **Centered Cookie Graphic**: Beautiful inline SVG cookie styled with modern CSS gradients and shadows.
- **Click Counter**: Increments every time you click on the cookie.
- **Interactive Animations**: Floating "+1" visual feedback on each click and press effect.
- **Persistence**: Remembers your click count across page reloads using browser `localStorage`.
- **Reset Functionality**: Easy reset button to clear your score back to zero.

## How to Run

1. Simply open `index.html` in any modern web browser (e.g. Chrome, Firefox, Safari, Edge).
2. Alternatively, serve the project using a simple local server:
   ```bash
   python3 -m http.server 8000
   ```
   Then open `http://localhost:8000` in your web browser.
